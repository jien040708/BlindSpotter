## 3.1 EIGAT (20 Epochs) ⭐ AUROC 최고

### 특징
- **구조**: Expert-Informed Graph Attention Network
- **입력**: Single frame (현재 시점만)
- **학습**: 20 epochs (완료)
- **성능**: AUROC 0.912 (매우 우수)

### 성능 평가

```
Validation 성능:
  ✓ AUROC: 0.9123 (최고!)
  ✓ AUPRC: 0.5095 (매우 좋음)
  ✓ Best F1: 0.5518 (좋음)

Test 성능:
  ✓ AUROC: 0.8574 (프로덕션 적합)
  ✓ AUPRC: 0.3183 (양호)
  ✓ Best F1: 0.4658 (사용 가능)
```

### 강점 ✅
1. **가장 높은 AUROC** (0.912)
   - ROC 곡선 면적에서 최우수
   - 분류 성능이 가장 좋음

2. **안정적인 일반화**
   - Validation (0.912) vs Test (0.857): 5.5% 차이 (양호)
   - 과적합 거의 없음

3. **빠른 학습**
   - Single-frame이라 학습 속도 빠름
   - 20 epochs 완료에 시간 효율적

### 약점 ❌
1. **시간 정보 부재**
   - VRU의 움직임 패턴 학습 불가
   - 현재 위치만으로 판단

2. **AUPRC에서는 ST-GCN에 밀림**
   - AUPRC 0.510 < ST-GCN 0.535 (5.0% 차이)
   - 클래스 불균형 데이터에서는 ST-GCN이 약간 우수

### 평가
🟢 **프로덕션 배포 가능** (AUROC 0.857, Best F1 0.466)

  ✓ Best F1: 0.6620 (최고!)

  ✓ Best F1: 0.5150 (우수)

1. **Temporal 정보의 위력**
   - AUPRC 0.535: 가장 높음 (클래스 불균형 극복)

## 4.3 최종 추천

### 🏆 **ST-GCN (20 Epochs 예상)이 최적 선택**

#### 이유

1. **자동주행 블라인드 존 감지의 특성**
   ```
   - 위험 여부를 정확히 감지해야 함
   - 오경보보다 위험 놓침이 더 위험
   - 따라서 Best F1 (0.670) > AUROC (0.885)
   ```

2. **AUPRC의 중요성**
   ```
   - 데이터 불균형: 위험 1.2%, 정상 98.8%
   - AUPRC는 이런 불균형을 극복하는 지표
   - ST-GCN AUPRC 0.540 > EIGAT 0.510
   ```

3. **실제 위험 감지율**
   ```
   ST-GCN: Best F1 0.670
     → 100명 VRU 중 67명 감지, 33명 놓침
   
   EIGAT: Best F1 0.552  
     → 100명 VRU 중 55명 감지, 45명 놓침
   
   → ST-GCN이 12명 더 감지 (생명 구하기)
   ```

4. **시간 정보의 중요성 입증**
   ```
   현재 움직임만 본다: EIGAT (0.912 AUROC)
   + 과거 움직임도 본다: ST-GCN (0.670 Best F1)
   
   → 같은 데이터인데 F1이 20% 향상!
   ```
