### 2.2 임계값 최적화 분석

#### EIGAT - Best F1: 0.466 @ τ=0.28

```
성능 곡선:
  - Precision (파란색): τ=0에서 1.0 → τ=1.0에서 0.0으로 부드럽게 감소
  - Recall (빨간색): τ=0에서 1.0 → τ=1.0에서 0.0으로 부드럽게 감소
  - F1 점수: τ=0.28에서 최고값 (0.466)

의미:
  ✓ Precision과 Recall의 최적 균형 달성
  ✓ 약 46.6%의 F1 스코어는 합리적 수준
  ✓ τ를 0.28로 설정하면 최고 성능
```

```
성능 곡선:
  - Precision: 거의 0에 가까움
  - Recall: τ=0.17에서만 존재
  - F1: 매우 낮음 (0.071)

의미:
  ⚠️ 낮은 임계값에서만 양성 포착
  ⚠️ 대부분 False Positive
  ⚠️ 신뢰성 낮음
```

```

  - Precision/Recall 모두 거의 0
```

## 4. 주요 발견사항

### 4.1 EIGAT의 성공 이유

1. **Expert Features의 강력함**
   - Blind zone geometry 정보 활용
   - Vehicle dynamics 반영
   - 단일 프레임만으로도 충분한 정보 포함

2. **간단하고 효율적**
   - 단순한 아키텍처 (1 layer, 2 heads)
   - 빠른 훈련 (20분)
   - 높은 성능

3. **안정적 학습**
   - 일관된 상승 곡선
   - 과적합 없음
   - 명확한 판별력

### 4.2 ST-GCN의 한계

1. **불안정한 훈련**
   - Validation 곡선이 노이즈 많음
   - Epoch마다 성능 변동

2. **Temporal 정보의 제한성**
   - 5 frames의 history가 충분하지 않음
   - GRU로 정보 손실 가능

3. **낮은 효율성**
   - 훈련 시간 대비 성능 향상 미미
   - 5 epochs가 20 epochs EIGAT만 못함

### 4.3 MR-GCN의 실패 원인

1. **모델 구조 부적합**
   - 이 문제에 적합하지 않은 아키텍처
   - 충분한 학습 용량 부족

2. **학습 불안정**
   - 20 epochs 후에도 성능 개선 거의 없음
   - Epoch 13에서 최고점 이후 다시 하락

3. **예측 점수 분포 실패**
   - 양성/음성 분리 완전 실패
   - 대부분 동일한 낮은 점수 할당

## 5. 의료/안전 관점에서의 해석

### 안전성 평가 (Autonomous Driving Context)

**EIGAT (권장) 🟢**
```
Recall @ High Precision: ~41% (epoch 5)
  → 실제 출현 사건의 41% 포착
  → 거짓 경보 비율 낮음 (65% 정밀도)
  → 안전 시스템으로 실용적 수준

False Negative Rate: ~59%
  → 중대한 위험: 절반 이상의 사건 놓칠 수 있음
  → 다른 센서와 함께 사용 필수 (앙상블)
```

**ST-GCN (보조) 🟡**
```
Recall이 더 낮음 (~23% test)
  → 더 많은 사건 놓침
  → 단독 사용 부적절
  → 앙상블의 일부로 활용 가능
```

**MR-GCN (사용 불가) 🔴**
```
거의 무작위 성능
  → 상용 시스템에 부적절
  → 재훈련 필요
```

## 6. 권장사항

1. **EIGAT를 기본 모델로 채택**
   - 단독 성능이 가장 우수
   - 빠른 추론 속도
   - 배포 준비 완료

2. **앙상블 검토**
   - EIGAT (40%) + ST-GCN (20%) + 다른 센서 (40%)
   - 다중 신호 활용으로 Recall 향상

### 6.2 중기 (추후 개선)
1. **하이퍼파라미터 튜닝**
   - ST-GCN의 history 길이 조정
   - Learning rate 최적화

2. **Hard example mining**
   - MR-GCN이 실패한 케이스 분석
   - 데이터 다양화

3. **Temporal 모델 재설계**
   - 더 깊은 구조
   - 다른 시간 윈도우

### 6.3 장기 (구조 개선)
1. **Multi-task learning**
   - Blind zone emergence 외 다른 목표
   - Cross-task 정규화

2. **Transfer learning**
   - EIGAT의 학습된 피처 활용
   - Fine-tuning으로 ST-GCN 개선

3. **실시간 데이터 활용**
   - 온라인 학습
   - Concept drift 대응
